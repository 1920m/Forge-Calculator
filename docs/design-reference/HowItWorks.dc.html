1

Average multiplier

Every ore has a multiplier. The craft uses the average, weighted by how many of each you add.
M = sum(multiplier x count) / total ores
Dark Knight example: Sun Stone 9, Lucky Cat 8, Sealed Curse 8, Roosite 5 gives M = 12.51.
2

Class odds

Only the total number of ores sets which classes can come out, from 3 to 55 ores. A class is greyed out in the game until you have enough ores, and the odds table is the same in every world.
World 3 and later swap some weapon classes (Gauntlets to Mace, Katana to Axe, Greatsword to Spear).
3

Variant odds

Inside a class each variant has a count c. Rarer variants have a bigger c.
P(v) = (1 / cv) / sum(1 / cj)
4

Primary ore

The ore you add the most of is the primary ore. Ties go to the highest multiplier. It sets how the item looks and its rarity.
5

Traits

A trait only activates when its ore is at least 10% of the craft. It then rises in a straight line and is at full strength from 30%. The same strength also scales negative effects.
6

Defence and damage

Armour and weapons use the same multiplier, then your craft quality.
Defence = ceil(2 x health % x M x quality)
Damage = ceil(2 x base damage x M x quality)
Quality is a straight percentage and results round up to two decimals. The quality label names are unverified.
7

Enhancement

Each enhancement level adds 5% of the base stat, from +0 to +10. This calculator shows the stat at every level, not the chance to succeed.
stat = value x (1 + 0.05 x level)
Try it in the calculator
8

Worked example

Dark Knight Chestplate: M = 12.51, 100% quality, base 625.5. At +10 it reaches 938.25 (625.5 x 1.5).
